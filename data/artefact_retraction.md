## 1. 被撤回的声称（当时的说法）

 对齐消融（`alignment_ablation.json:unmeasured_gene_artifact`）及引用它的  手稿 Results 第 3 段声称：

1. 322 基因面板经"228 基因跨队列交集"投影后，锚定队列（IMvigor210）中仅 **158** 基因可测量表达，**70 基因完全未测量**（全零）；
2. 这 70 个未测量基因在 CLR（逐样本中心化）后**退化为 library-size 代理变量**，并**占据锚定 PC1 loading 平方质量的 88.7%**（0.88661，PC1 EVR 34.6%）——即锚定表示的第一主成分主要由"测序深度伪变量"而非生物学驱动；
3. 将面板限制到 158 个实测基因后，GSE78220 外部 AUC "恢复"到 **0.583–0.724**（5 个消融配置的区间；无 CI 排除 0.5）；
4. 由此衍生：零值处理敏感性结论（P0-6）——"多重替换无法为这 70 个基因代入取值，伪影由结构性未测量驱动"；以及手稿中 228/158/70 基因计数叙述（Methods 与 Results 多处）。

以上第 1–4 条**全部撤回**。

## 2. 真实原因（root cause）

**匿名化矩阵上的位置对齐错误**，叠加一个二级基因选择错误：

- IMvigor210 表达矩阵 `exmat.csv` 由上游 `mimifp/tfm_mUC` 匿名化：行标签替换为 `gene_1..gene_31085`，**行序保留 `counts(cds)` 的写出顺序**——该行序恰为 fData symbol（大写归一）**字母序**。
- 项目冻结管线（→→ S0）假设 **exmat 第 i 行 == fData 第 i 行**（fData 实为 entrez 字符串序）。两者排序不同 → 每一个"按基因名选行"的操作取到的都是**无关基因的行**。
- 二级错误：`Supplementary_Table_1_322_genes.csv` 第 1 列是**顺序行号 1..322 而非 Entrez ID**， `common_genes()` 将其当作 entrez，得到**伪随机"229 基因交集"**。
- 所谓"70 个未测量基因"只是错误行映射下**恰好全零的无关行**；"88.7% PC1 loading 质量"是错位行身份的结构性伪影。按恢复钥匙重选 320 个真实面板基因后：**全零基因 0 个**，PC1 loading 落在"零值基因"上的质量 = **0**（PC1 EVR 由 34.6% 变为 26.5%，结构改变）。

## 3. 如何被发现（P0-2 阳性对照执行中的性别锚定证伪）

修订包 P0-2（`positive_control.json`，IFN-γ 6 基因签名，Ayers et al. JCI 2017）要求按基因名进入 IMvigor210 exmat。执行中的**性别锚定 / 管家基因门**全部证伪位置对齐假设，7/7 不可能标志：

| 门 | 观察 | 判定 |
|---|---|---|
| DDX3Y 在"女性"中高表达（f/m≈0.97） | 不可能（Y 连锁、男性特异） | 证伪 |
| UTY 同样在女性中表达 | 不可能 | 证伪 |
| XIST 无女性偏倚（f/m≈1） | 不可能（应为女性高） | 证伪 |
| GAPDH 全零、ACTB 近零（行和 36） | 不可能（管家基因） | 证伪 |
| IFNG 在 bulk 中高表达 | 不可能（免疫细胞专属） | 证伪 |
| 顶级"男性特异"行携带错误 fData 标签 | 5/5 错标 | 证伪 |
| 样本列身份 | 头部样本 ID 与冻结 y 向量逐位一致 | **有效**（错误仅在基因行侧） |

阳性对照由此从"模型验证"转变为**数据取证入口**（Go/No-Go 级发现：冻结 S0 的"322 基因表示"实际建立在无基因身份的行上）。

## 4. 恢复方法（symbol 字母序钥匙）

- **阶段 1a（本地）**：9 个排序假设对性别锚定/管家/免疫门检验，唯一胜者：**exmat 第 j 行 == fData 按 symbol（大写归一）字母序排序后的第 j 个基因**。深度验证：8 基因 Y 连锁族全部男性特异（f/m 0.0005–0.002）；XIST f/m=673；行和 Top30 = MALAT1/COL1A2/FN1/ACTB…（教科书级）；免疫基因对 pData TC/IC 分级 Spearman 全部显著（如 CD274 ρ(TC)=0.523，p≈1e-26；CXCL9 ρ(IC)=0.608，p≈2e-36）；与外部队列基因平均 log-CPM 秩相关 ρ=0.81（GSE165252）/0.62（GSE78220），而旧位置对齐下 ≈0。
- **阶段 1b（溯源）**：本地三文件与上游 `mimifp/tfm_mUC` 逐字节一致（fData/pData SHA256 比对通过）；上游提取脚本显示 exmat 以 `counts(cds)` 行序写出、首列为 symbol，censored 版仅替换行标签。
- **阶段 1c（数值恒等）**：对 `SiYangming/IMvigor210CoreBiologies`（官方 IMvigor210CoreBiologies 镜像）`cds.RData` 提取的带标签 counts 矩阵逐行全值匹配：**31085/31085 行匹配、0 未匹配**；大小写排序歧义（145 行，均非面板基因）被裁决为 upper；322 面板基因两种排序行号完全一致。
- 钥匙导出为 `geo_data/imvigor210_labeled/exmat_row_key.csv`；总验证门 **PASS**（含 binaryResponse 68/230/50、面板可测量 320/322）。

## 6. 教训（ED10 / provenance 表用）

1. **匿名化矩阵禁止按位置连接**：行标签被剥离的矩阵与任何注释表的行序等同假设，必须先用独立锚（性别/管家/免疫）证伪或证实后才能进入分析。
2. **阳性对照是数据完整性审计**：P0-2 本为模型验证，其性别锚定门直接暴露了上游数据销毁性缺陷——评审级检查清单应强制包含此类"生物学不可能"门。
3. **逐级冻结 + 撤回留痕**：→→ 的逐版本冻结使伪影可定位到具体版本与键（`alignment_ablation.json:unmeasured_gene_artifact`）；本撤回文档与分析 manifest（`analysis_manifest.json`，含三文件 SHA256 与上游溯源）保证修正链条完整可复现。
4. **"消融出结构"不等于"结构为真"**：88.7% loading 质量在多重零值处理方案下"稳健"，但稳健的是**伪影本身**——稳健性分析无法拯救身份错误的输入。
